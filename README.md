# Node.js E-Commerce Application

## 1. Project Overview

This is a sample e-commerce website built using Node.js, Express.js, HTML, CSS, and JavaScript.

Users can browse products, search for items, filter products by category, and add products to a shopping bag.

This project is designed for Cloud, DevOps, Platform Engineering, and CI/CD training. It can later be extended to practise Docker, GitHub Actions, container registries, and cloud deployments.

## 2. Technologies Used

- **Node.js** – JavaScript runtime for the backend.
- **Express.js** – Web framework for the web server and REST APIs.
- **HTML** – Website structure.
- **CSS** – Styling and responsive design.
- **JavaScript** – Frontend interactions and API integration.
- **npm** – Package and dependency management.
- **Git and GitHub** – Version control and source code hosting.

## 4. Create the Application from Scratch

### Step 1: Create the Project Directory

```bash
mkdir nodejs-ecommerce-app
cd nodejs-ecommerce-app
```

### Step 2: Initialize the Node.js Project

```bash
npm init -y
```

This creates `package.json` with default project metadata.

### Step 3: Install Express.js

```bash
npm install express
```

Express.js is used to create the web server, expose API endpoints, and serve the frontend files.

### Step 4: Create the Application Files

```bash
mkdir public
touch server.js
touch public/index.html
touch public/style.css
touch public/app.js
touch .gitignore
```

### Step 5: Configure package.json

Add the following scripts to the existing `scripts` section in `package.json`:

```json
"scripts": {
  "start": "node server.js",
  "dev": "node --watch server.js"
}
```

Keep the existing metadata and dependencies generated by npm.

### Step 6: Develop the Application

Implement the backend in `server.js` and the frontend in the files under `public/`.

The Express server serves the website and provides APIs for retrieving product information and checking application health.

### Step 7: Install Dependencies

```bash
npm install
```

This installs the dependencies defined in `package.json` and updates the lockfile when necessary.

### Step 8: Run the Application

```bash
npm run dev
```

Open the website at:

http://localhost:3000

## 5. Run the Application from GitHub on Your Local Machine

You do not need to create the application files manually if the project is already available in GitHub. Clone the repository and install its dependencies.

### Prerequisites

Install the following:

- Node.js and npm
- Git
- A terminal such as Git Bash, PowerShell, or a Linux terminal

Verify the installations:

```bash
node --version
npm --version
git --version
```

### Step 1: Clone the GitHub Repository

Replace the example URL with your actual repository URL.

```bash
git clone https://github.com/YOUR_USERNAME/nodejs-ecommerce-app.git
```

### Step 2: Navigate to the Project Directory

```bash
cd nodejs-ecommerce-app
```

### Step 3: Install Dependencies

```bash
npm ci
```

`npm ci` installs the exact dependency versions recorded in `package-lock.json`. It is a good choice for a clean, reproducible setup when the lockfile is committed to GitHub.

### Step 4: Start the Application

```bash
npm run dev
```

Alternatively, use the regular start command:

```bash
npm start
```

### Step 5: Access the Website

Open your browser:

http://localhost:3000

The website should now be available on your local machine.

**Important:** Do not commit `node_modules/` to GitHub. The student installs the dependencies locally using `npm ci` or `npm install`.

## 6. API Endpoints

| Endpoint | Description |
|---|---|
| `/` | Displays the e-commerce website |
| `/api/products` | Returns the product list in JSON format |
| `/api/health` | Returns application health information |

Test the APIs in your browser:

- http://localhost:3000/api/products
- http://localhost:3000/api/health

## 7. How the Application Works

1. The user opens the website in a browser.
2. Express.js serves the HTML, CSS, and JavaScript files.
3. The frontend requests product data from `/api/products`.
4. The backend returns the product list as JSON.
5. Frontend JavaScript renders the products and handles search, category filters, and shopping bag interactions.
6. The health endpoint provides a basic application health response.

## 9. Important Notes

- This is a training/demo application, not a production-ready e-commerce platform.
- Product data is maintained in the application code.
- The shopping bag is maintained in browser memory and is not persisted.
- The application does not include a database, authentication, payment processing, or persistent order management.
- Product images and Google Fonts require an internet connection.
